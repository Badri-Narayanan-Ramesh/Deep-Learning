# Deep-Learning
1) Facial Expression Recognition using Deep CNN and Transformers

- Implemented a deep CNN using the DeXpression architecture for automatic facial expression recognition (anger, fear, surprise, etc.).
- Trained and evaluated the model with 5-fold Cross-Validation on the Extended Cohn–Kanade (CK+) dataset.
- Achieved 99% mean training accuracy and 98% mean test accuracy, demonstrating robust generalization on canonical FER benchmarks.
- Repeated the same with Transformer architecture.
